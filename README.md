# Mini Test Solutions

Solutions for the coding interview mini test with two tasks:

## Task 1: Small Program
Numbers 1-100 in reverse order with special rules (no primes, Foo/Bar replacements)

## Task 2: Weather Forecast
5-day weather forecast for Jakarta using OpenWeatherMap API

## Implementations

**JavaScript Version** - [js-vers branch](../../tree/js-vers)  
Complete solutions for both tasks using HTML/CSS/JavaScript

**Python Version** - [python-vers branch](../../tree/python-vers)  
Complete solutions for both tasks using Python

## Usage

1. Choose your preferred implementation branch
2. Follow the setup instructions in that branch's README
3. Both tasks are included in each branch
